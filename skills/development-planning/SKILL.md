# Development Planning

Cross-cutting guidance for planning, design, and requirements work.

Load one of the focused planning skills when the trigger applies:

- **`iterative-development`** — Starting new features, refining existing code, or
  evolving the domain model.
- **`use-case-creator`** — Writing use cases, specifying requirements, or
  documenting system behavior in AsciiDoc.
