# Immutables

Builders for classes with complex constructors, generated by the Immutables
annotation processor, plus the `@Data` metamodel for test constants.

## Dependencies

- `org.immutables:value` (annotation processor)
- `org.immutables:value-annotations`, `org.immutables:builder` (compile-only)
- `org.immutables:datatype` (compile-only, for `@Data`)

## Factory builders

Put `@Value.Style` on a factory class and mark each factory method
`@Builder.Factory`. The processor generates a `UserBuilder` from the method's
parameters; the class keeps a hand-written `builder()` delegate.

```java
import java.util.HashSet;
import java.util.Set;
import org.immutables.builder.Builder;
import org.immutables.value.Value;

@Value.Style(newBuilder = "create", jdk9Collections = true, jdkOnly = true)
final class UserFactory {

  private UserFactory() {}

  @Builder.Factory
  static User user(String name, Set<IdentityProviderUser> identityProviderUsers) {
    return new User(User.UserId.create(), name, new HashSet<>(identityProviderUsers));
  }
}

// User is hand-written; UserBuilder is generated
public class User {

  public static UserBuilder builder() {
    return UserBuilder.create();
  }
}
```

## Record builders

Put `@Value.Builder` directly on a record. The processor generates a
`<Type>Builder`; the record keeps a hand-written `builder()` delegate.

```java
import org.immutables.value.Value;

@Value.Builder
public record GitContext(@Nullable String nearestTag, long distanceFromTag) {
  public static GitContextBuilder builder() {
    return new GitContextBuilder();
  }
}
```

## Datatypes metamodel

Put `@Data` on the record and the processor also generates
`Datatypes_<Type>`: a nested `<Type>_` metamodel with a `String` constant per
component, named for the component with a trailing underscore. Use the
constants with AssertJ `hasFieldOrPropertyWithValue` so failure messages name
the field. For JPA entities use the Hibernate metamodel instead — see
`references/hibernate.md`.

```java
import org.immutables.datatype.Data;
import org.immutables.value.Value;

@Value.Builder
@Data
public record GitContext(@Nullable String nearestTag, long distanceFromTag) {
  public static GitContextBuilder builder() {
    return new GitContextBuilder();
  }
}
```

```java
import com.example.semver.Datatypes_GitContext.GitContext_;

assertThat(context).hasFieldOrPropertyWithValue(GitContext_.NEAREST_TAG_, "v1.0.0");
```
