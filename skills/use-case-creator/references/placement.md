# Spec Placement

Specs live in the ticket description and in the repo. The ticket is the
record while work is shelved.

`docs/use-cases/` is the default directory for a use case file. A spec goes
at the highest visible level it applies to. A UX-level use case lives at
the UX level even when it affects code all the way down.

Long-term open question: should a dedicated `use-cases` repo own these
files, or should owning repos keep them? No local or GitHub repo named
`use-cases` or `specs` exists today.

Use cases stay deferred. Most tickets need none.
